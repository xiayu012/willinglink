# 室友矛盾对白语料库（Roommate Conflict Dialogue Corpus）

## 用途

这组语料的目标是采集“多人共同生活发生矛盾时，人们实际上会怎么说话”的真实对白，
用于替代 WillingLink 里原来的合成评测场景，给后续评测、提示词与行为对齐提供更接近
真实生活的原材料。当前只保留原始对白与出处，不包含任何评测断言或可执行场景。

## 来源与许可

- 对白片段全部来自公开剧本/字幕网站 **Springfield! Springfield!**
  （https://www.springfieldspringfield.co.uk/ ）的电视剧分集脚本。
- 片段按来源逐字摘录，只做了三类最小处理：
  1. 修正脚本站点本身的大小写/OCR 误写（如 `SCHMlDT` → `SCHMIDT`、`NlCK` → `NICK`）；
  2. 给原本未标注说话人的续行按上下文补上人物名；
  3. 合并分行的同一句台词，不做含义层面的改写。
- 原始网址逐个标注在每个片段的【原始网页】。这些对白版权归原剧集权利方所有，
  本仓库仅作内部研发语料使用，不对外分发。

## 采集优先级

按老板要求，优先保留 A 档：非常像现实合租矛盾、2–4 人、上下文完整、对白自然、
冲突过程完整。宁缺毋滥，不为凑数保存弱相关、纯恋爱、纯家庭或极端戏剧化内容。

## 编号

片段统一写在 `corpus.md`，编号 001 起连续递增。每个片段结构为：

【编号】 / 【来源作品】 / 【季/集】 / 【来源类型】 / 【冲突类别】 /
【参与人物】 / 【冲突背景】 / 【对白片段】 / 【这个片段为什么有价值】 / 【原始网页】

## 使用说明

当前这些片段是“原始语料”，不是 `coliving-eval` 的可执行场景。
要把某条变成可跑评测，需要再按 `lib/chat/coliving/evals/schema.ts` 的
`EvalScenario` 结构做二次加工（定 people/turns/expect）。本目录保持低耦合，
方便以后整体删除或迁移。
